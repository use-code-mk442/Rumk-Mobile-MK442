# Rumk Mobile — MK442

نسخة جوال جديدة من Rumk بهوية أرجوانية/سماوية، وخلاصة عمودية بمقطع واحد في كل شاشة، ومشروع Android WebView يمكن بناء APK له عبر GitHub Actions.

**المصمم:** مجد الخميس (MK442)  
**كود المبدع في Fortnite:** `MK442`  
**الحقوق:** © Rumk / MK442. جميع الحقوق محفوظة لهوية وتصميم وبرمجة التطبيق. الفيديوهات الخارجية تبقى لأصحابها وتُشغّل من خلال روابط/مشغلات المنصات الأصلية.

## ما الذي يعمل؟

- عند التشغيل يحاول التطبيق إظهار نتائج بحث YouTube للموضوع الافتراضي، ثم يسمح بتغيير موضوع البحث.
- زر الإعدادات يغيّر المصدر الافتراضي بين YouTube وTikTok وSnapchat وX وFacebook وInstagram، ويحفظ الموضوع المختار.
- يمكن إضافة رابط عام لمقطع عبر زر `+`. تُضمّن روابط YouTube وTikTok وInstagram وX وFacebook داخل الخلاصة عندما تسمح المنصة بذلك. بعض روابط Snapchat لا توفر مشغّلًا قابلًا للتضمين، لذلك تظهر كبطاقة فيها زر فتح المصدر.
- الإعجاب والمتابعة والحفظ محلية على الجهاز فقط؛ ليست حسابات أو تفاعلات متزامنة مع مستخدمين آخرين.
- لا يوجد مجلد فيديوهات محلي مضمن؛ المقاطع تأتي من الإنترنت أو من الروابط التي تضيفها.

## حدود مصادر المقاطع

- بحث YouTube في APK يستخدم موجز بحث عام بدون مفتاح كحل خفيف. قد تغيّر YouTube هذا المسار؛ عندها يمكن إضافة مفتاح YouTube Data API من الإعدادات. احتفظ بالمفتاح لنفسك ولا تضع مفتاحًا مفتوحًا في مستودع عام.
- المنصات الأخرى لا تسمح لتطبيق عام بالبحث الشامل في جميع مقاطعها دون واجهات مطوّر وصلاحيات مناسبة. لذلك يفتح زر البحث نتائج المصدر، ثم تضيف رابط المقطع العام إلى Rumk. التضمين يعتمد على إعدادات الخصوصية وسياسات المنصة وتوفر المقطع.
- التطبيق لا ينزّل مقاطع الآخرين ولا يتجاوز قيود المشاهدة الخاصة أو المحتوى المحذوف.

## إنشاء APK من GitHub

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع **كل محتويات هذا المجلد** (بما فيها مجلدا `.github` و`android`). لا ترفع ملف ZIP وحده داخل المستودع.
3. افتح تبويب **Actions** في المستودع. سيبدأ سير العمل `Build Rumk Android APK` بعد الرفع. ويمكن تشغيله يدويًا من زر **Run workflow**.
4. افتح آخر تشغيل ناجح، وانزل إلى **Artifacts**، ثم نزّل `Rumk-MK442-Android-APK`.
5. فك ضغط ملف الأثر، ثم ثبّت `app-debug.apk` على هاتف Android. قد تحتاج السماح بالتثبيت من المصدر الذي نزّلت منه الملف.

يخرج البناء ملف Debug APK موقّعًا بمفتاح debug كي يمكن تثبيته للاختبار. هذا ليس إصدار متجر Google Play موقّعًا بمفتاح إنتاج.

## بناء المشروع محليًا

شغّل `python sync_web_assets.py` أولًا، ثم افتح مجلد `android` في Android Studio مع Android SDK وJDK 17، ونفّذ Gradle task `assembleDebug`. يوجد ملف الواجهة القابل للتجربة في `site/index.html`، والنسخة التي تُضمّن داخل Android تُزامن تلقائيًا بواسطة `sync_web_assets.py` من مجلد `site` أثناء بناء GitHub Actions.

## ملاحظات فنية

- Package ID: `com.mk442.rumk.debug` لنسخة Debug.
- `minSdk 23`, `compileSdk 35`, وJava 17.
- لا توجد بيانات اعتماد API مضمنة في الملفات.
- حقوق مقاطع الجهات الخارجية وأسماؤها وشعاراتها تعود إلى أصحابها ومنصاتها.
